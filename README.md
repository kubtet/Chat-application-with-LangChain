# LangChain & RAG – Learning Repository

Welcome to my **Generative AI and Large Language Models (LLMs) learning repository**!

This repository contains a collection of Jupyter notebooks, practical examples, and supporting materials covering the fundamentals of working with Large Language Models, the OpenAI API, LangChain, and Retrieval-Augmented Generation (RAG).

The main goal of this project is to explore and understand the building blocks of modern LLM-powered applications through hands-on experimentation and practical implementations.

---

## Topics Covered

This repository is organized around several key areas of Generative AI:

- **OpenAI API** – Working with OpenAI models and their capabilities.
- **LangChain** – Understanding LangChain components and the LangChain Expression Language (LCEL).
- **Prompt Engineering** – Prompt templates, few-shot prompting, and chat prompt templates.
- **Retrieval-Augmented Generation (RAG)** – Document loading, text splitting, embeddings, vector stores, and retrieval.
- **Vector Databases** – Storing and managing embeddings for semantic search.
- **Output Parsers** – Structuring and processing LLM responses.
- **Similarity Search** – Finding semantically relevant information using embeddings.
- **LLM Applications** – Combining different components to build more advanced workflows.
